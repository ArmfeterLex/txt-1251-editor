# TXT 1251 Editor

Текстовый редактор на C# Windows Forms с поддержкой кодировки Windows-1251.

## Функциональность

- Открытие текстового файла в кодировке Windows-1251
- Сохранение текста в той же кодировке
- Многострочное текстовое поле
- Обработка ошибок (файл не найден и др.)
- Фиксированный путь к файлу

## Интерфейс

- Кнопка "Открыть" — загружает текст из файла с кодировкой 1251
- Кнопка "Сохранить" — записывает изменения в той же кодировке
- Текстовое поле для редактирования

## Куда можно встроить

- В редакторы конфигурационных файлов в старой кодировке
- В программы для работы с legacy-документами
- Как пример работы с кодировками в C#
- В утилиты конвертации текста

## Требования

- Windows
- .NET Framework / .NET Core с WinForms
- Файл по указанному пути (или измените в коде)

## Примечание

Файл открывается и сохраняется по фиксированному пути. Кодировка явно указана как Windows-1251.
